РИПК — версия 9.0

Электронный каталог грузоподъёмного оборудования РИПК 2026.

Что сделано в версии 9.0:
- сохранены 67 позиций электронного каталога;
- значительно расширены реальные табличные характеристики по страницам 2–16;
- добавлены сведения с технических страниц 17–36 там, где скан позволяет безопасно передать текст;
- для неоднозначно читаемых числовых данных сохранена ссылка на исходную страницу вместо выдумывания значений;
- добавлены визуальные отметки наличия технических данных;
- сохранены поиск, фильтр по категориям, карточки изделий, исходные страницы, PDF и запрос цены;
- сайт остаётся статическим и подходит для публикации через GitHub Pages.

Первичный источник технических сведений — каталог РИПК 2026, включённый в архив. При коммерческом заказе и техническом согласовании конкретные параметры следует сверять с исходной страницей каталога.
