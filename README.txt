РИПК — версия 10.0

Профессиональная электронная версия каталога грузоподъёмного оборудования РИПК 2026.

В версии 10.0:
- 67 позиций;
- 8 категорий;
- поиск по названию, категории, странице и артикулу РИПК;
- карточки изделий с артикулом РИПК-001 ... РИПК-067;
- промышленный вид карточек и расширенная карточка изделия;
- техническая таблица там, где данные были надёжно перенесены из исходного каталога;
- для остальных позиций показана исходная техническая страница PDF;
- кнопка запроса коммерческого предложения с названием изделия и артикулом;
- кнопка открытия соответствующей страницы PDF;
- копирование артикула;
- закрытие карточки клавишей Escape;
- адаптация для телефона;
- исходный PDF каталога 2026 и изображения страниц сохранены.
